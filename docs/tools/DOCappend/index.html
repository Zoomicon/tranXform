DOCappend - append a document to a Word document

DOCappend appends a document (including HTML) as a new page with an optional title to a Word document (.DOC/.DOCX files), creating the target document if it doesn't exist.

Drag-drop a source or new Word document, followed by the document to append, onto the DOCappend.vbs file. An optional title can be supplied as a third command-line parameter.

Syntax: DOCappend sourceOrNewFile appendFile [title]

For the above to work you need Microsoft Word installed and Windows Script Host (pre-installed by default at WinXP and Windows Vista, can get it from http://msdn2.microsoft.com/en-us/library/ms950396.aspx)
